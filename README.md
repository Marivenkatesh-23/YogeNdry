# YogeNdry

Smart, retrofitted laundry for hostels and campuses. An Arduino UNO R4 WiFi with a vibration sensor on each washing machine shows residents which machines are free, gives managers maintenance alerts, and lets students donate clothes they no longer wear.

This repo holds the pitch website with a live demo dashboard (simulated telemetry).

## Run it

Double-click `start.bat` (Windows), or run:

```
python -m http.server 8080
```

Then open http://localhost:8080.
